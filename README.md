# website-builder: i siti demo

Un repo solo, una cartella per sito: `sito-<slug>/`. Ogni sito è statico (HTML + CSS + JS), senza build.

- Online su Vercel, progetto `sito-<slug>` → `https://sito-<slug>.vercel.app`. Deploy da CLI dalla cartella del sito (`vercel --prod`):
  Vercel non è collegato a GitHub.
- Video di presentazione in `sito-<slug>/video/`, fuori dal deploy grazie al `.vercelignore` della cartella.
- Procedura completa: `~/.claude/skills/website-builder/SKILL.md` e il CLAUDE.md della cartella WEBSIDE BUILDER.

Fino al 18/10/2026 ogni sito aveva un repo `sito-<slug>` separato: sono stati importati qui con tutta la storia.
